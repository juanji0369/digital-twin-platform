# 平台内存状态

平台在进程内维护以下索引，随当前配置和接收消息更新。

| 索引 | 内容 |
| --- | --- |
| gatewayId → 当前流 | 已认证双向流、连接标识、连接状态、最近接收时间 |
| gatewayId → 网关运行状态 | 快照对应的生效版本、设备/连接/功能总数、存储状态、非正常连接及生成时间 |
| gatewayId/deviceId/communicationId → 连接问题 | 当前配置下 UNKNOWN 或异常连接的 status 及进入当前状态的时间 |
| gatewayId/deviceId/propertyId → 最新记录 | 正常值或异常 code、采集时间、上报时间 |
| gatewayId/deviceId/propertyId → 当前功能 | 当前配置中的功能及通信归属 |

## 会话与状态

网关连接状态由认证流及生命周期维护，旧流结束回调无法覆盖当前流。
StatusReportReq 的较新快照完整替换网关配置总数、connectionIssues 和 storage，并重建当前配置下的连接问题索引。连接恢复通过新快照移除对应项，空列表表示快照对应配置中的连接均已确认正常。storage 的两个状态项始终保留，各自提供 status 和 timestamp。
设备是连接问题的归属和查询入口，查询返回该设备各通信配置的 UNKNOWN 或异常状态。网关流状态、快照生成时间和连接问题分别提供，网关离线时保留最近快照供展示。

## 最新记录

按 gatewayId、deviceId、propertyId 定位记录。App 比较上报记录的采集时间戳：无当前记录时保存，有记录时仅在时间戳更大时更新内存，时间戳相同或更小时保持当前记录及其时间不变。
接受旧配置下的在途记录，只检查当前功能 ID 是否存在，不按当前通信归属或配置版本过滤。功能在同一设备内迁移通信配置时保持 ID 和最新记录，后续采集按时间规则覆盖。当前结果保存互斥的 value/code，以及采集时间和批次上报时间，不设置有效期。
功能读数状态直接由最新记录派生：无记录为 unknown，value 为 ok，code 为 error。连接变化保持最新记录及其读数状态。
缺少记录时返回空，进程重启后等待新上报。

## 查询与同步

查询从内存读取网关运行、具体连接问题和功能读数，分别提供内容及对应时间。最新记录或状态更新后，向前端推送对应对象的变化。
配置存在性检查、快照替换和最新记录写入使用同一同步边界。删除对象时清除对应索引和缓存；当前配置中不存在的设备、通信配置及功能不进入当前状态视图。
